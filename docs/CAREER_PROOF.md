## LinkedIn project description
I built a hardware-independent **Cloud-Connected Smart Plant Care & Watering System** to explore what an end-to-end IoT cloud application looks like beyond a basic sensor prototype.

The system uses a Python virtual IoT node to generate realistic soil-moisture, temperature, humidity, light, and water-tank telemetry. Readings are sent through a FastAPI REST API, validated and stored in SQLite/PostgreSQL, evaluated by an automated watering engine, and surfaced through a React dashboard.

Key engineering work included:
- IoT sensor simulation with realistic trends
- REST-based telemetry ingestion
- Relational cloud-ready data model
- Automated irrigation with safety controls
- Historical analytics and charts
- Low-moisture, high-temperature, tank and offline alerts
- API-key protected device control endpoints
- Dockerized multi-service deployment
- Automated backend tests
- Architecture prepared for ESP32 + MQTT + managed cloud services

This project helped me connect **Cloud Computing + IoT + Backend Engineering + Automation + Full-Stack Development** in one practical system.
